# 건강한 하루 탐정

초등학교 1학년 학생이 생활 장면을 관찰하고 건강한 습관으로 바꾼 뒤, 그 습관이 몸과 마음에 주는 도움을 연결해 보는 학습 웹앱입니다.

## 주요 기능

- 하루 생활 패턴 → 위생 → 식생활 → 신체활동 → 마음·관계의 고정된 순서
- 영역별 8문항, 총 40문항 문제은행에서 한 문제씩 무작위 출제
- 직전 활동과 같은 문제가 바로 반복되지 않도록 처리
- 첫 오답에는 힌트, 두 번째 오답에는 정답 선택지 강조
- 건강한 습관과 몸·마음의 도움을 각각 연결하는 2단계 활동
- 두 학습 목표를 따로 보여주는 친근한 성취 화면
- 현재 문제에서 실천할 생활습관을 골라 학습지 약속으로 연결
- 로그인, 관리자 페이지, 데이터베이스, 개인정보 및 학습 결과 저장 없음
- 큰 터치 영역과 반응형 화면으로 태블릿·휴대전화 지원

## 실행 방법

정적 웹앱이므로 `index.html`을 웹 서버로 열면 됩니다.

```bash
npm run dev
```

문제은행 구성 검사는 다음 명령으로 실행할 수 있습니다.

```bash
npm run check
```

문항은 `questions.js`, 화면 동작은 `app.js`, 디자인은 `styles.css`에 분리되어 있습니다.
